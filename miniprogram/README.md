# YouthTempo 微信小程序第一版

覆盖邮箱 OTP 登录、个人资料与知情确认、SWEET 五维记录、AI 小结、历史记录和支持入口。第一版仅开放学生与 18–25 岁青年个人使用；家长、老师和学校负责人继续使用网页工作台。

## 发布前配置

1. 在 `config.js` 填写 Supabase 的 publishable/anon key。该密钥可以出现在客户端，但不得填写 `service_role` 或 `sb_secret_`。
2. 在微信公众平台配置 request 合法域名：正式 CloudBase 域名和正式 Supabase 项目域名。
3. 在微信开发者工具中导入本目录，填写真实小程序 AppID，并完成隐私保护指引、类目和体验版审核。
4. 用 14–17 岁虚拟学生账号验证监护人确认门槛；用 18–25 岁虚拟账号验证独立确认、保存、读取和删除。

`config.js` 不包含秘密，但发布前的真实 publishable key 仍应通过发布流程注入和复核，避免误填服务端密钥。
