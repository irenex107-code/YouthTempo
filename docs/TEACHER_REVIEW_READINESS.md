## 本分支已实现的产品方向

| 方向 | 会上可展示的内容 | 上线前仍需的证据 |
|---|---|---|
| SWEET | 非诊断性自我观察；轻量记录可日用，完整 SWEET 建议每周、随时可做；无连续打卡惩罚 | 双语真机与学生理解核对 |
| 青序花园 | 私有植物阶段、水滴式轻量记录、SWEET 参与汇总、周/月次数与应用内提醒偏好；只根据参与成长 | 隔离数据库读写、删除与 RLS |
| 年龄分流 | 14–17 岁的家校医社支持、审核社区和求助；18–25 岁的主题空间、记录与自主支持 | 两年龄组真实隔离账号浏览器验收 |
| 家长边界 | 家长教育与 SWEET Talk 保留；新关系拒绝，历史关系不应赋予学生记录读取；成年人独立 | Migration、直接 Data API、旧 session 及历史关系修复核对 |
| 成年人解忧室 | 邀请、规则、跨校主题房间、群消息、短轮询、举报、屏蔽、静音、删除、值班与人工审核 | 隔离账号端到端、DB 触发器/RLS、运营值班；正式开关维持关闭 |
| AI 辅助 | 确定性危机识别优先；可选 AI 分类仅送人工队列，不自动公开不安全内容或作最终决定 | 中英文高低风险真实链路、人工值班与告警 |
| 支持人员 | 专业咨询人员、社工、培训倾听志愿者、邀请制学校值班老师；私有材料与人工审核 | 四类账号、私有 Storage、学校职责、培训和资质人工核验 |
| 支持事项 | 青少年主动求助与人工转介；成年人内部咨询申请、主备支持者、接受/拒绝、改期、更换、撤权、结束及反馈 | 隔离数据库全流程和数据最小化复核 |
| 轻量反馈 | 可跳过、七天冷却、三道简短问题与可选文本；后台按年龄/功能汇总 | 隔离账号与冷却并发测试、真人安全复核流程 |

家校医社指家庭教育资源、学校责任人、医疗/专业转介和社会工作或社区资源；平台的审核社区是另一个独立空间。SWEET 与花园结果不能诊断、评分健康程度或自动决定支持者资格。

## 当前不对公众开放

正式一对一心理咨询、未成年人直接预约、支付、随机陌生人私聊和公开专业人员评分均未开放。公开咨询页显示服务准备中；创建成人咨询事项的服务端开关默认关闭。成年人聊天室有独立开关和排班门槛，不能因页面可访问就认为可以开房。未成年人仅能提交支持需要，由人工评估、学校、社工、医疗或专业资源承接。

## 会上建议的演示顺序

1. 14–17 岁工作台及家校医社支持请求。
2. SWEET 的非诊断说明、轻量记录与青序花园。
3. 18–25 岁工作台与受邀成年人解忧室。
4. 高风险预筛、隐匿消息和人工审核队列。
5. 四类支持人员申请与受限审核。
6. 正式咨询公开关闭页及内部流程原型。
7. 轻量反馈与匿名汇总。

演示使用隔离账号与虚构内容。若隔离数据库仍不可用，演示只覆盖公开页和代码/界面结构，不冒充聊天室或支持事项的真实生命周期。截图不得出现私人材料、正文、邮箱或真实姓名。

## 请张老师与运营共同决定

- 专业人员最终考评、学生体验反馈的权重、专业督导与资质复核方式。
- 暂停、试用、移除的人工标准，是否以及何时公开任何评价。
- 正式咨询何时公开，哪些年龄及地区纳入、可用时间和转介边界。
- 未成年人未来是否允许选择性家长分享及所需产品、学校、隐私签署。
- 每个房间和支持请求的具名值班、备班、危机升级负责人、职责时段和离线紧急路径。
